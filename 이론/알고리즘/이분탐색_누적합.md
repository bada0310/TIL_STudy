# 📝 알고리즘 핵심 노트: 매개변수 탐색 + 2차원 누적합

## 1. 사고의 전환: 매개변수 탐색 (Parametric Search)
최적화 문제(가장 늦게 비를 맞는 시간 찾기)를 **결정 문제(T 시간에 버틸 수 있는가? Yes/No)**로 뒤집어 이분 탐색을 적용하는 기법입니다.

*   **탐색 대상:** 공간(좌표)이 아닌 **정답(시간, 거리 등)** 자체를 탐색합니다.
*   **스무고개 원리:** T초일 때 `Yes`라면 T보다 작은 시간은 당연히 `Yes`이므로, 탐색 범위를 절반씩 날려버리며 $O(\log N)$ 속도로 정답을 찾습니다.
*   **핵심:** 컴퓨터에게 `Yes/No` 질문을 던지는 판별 함수(`check(T)`)를 얼마나 빠르게 동작하게 만드느냐가 관건입니다.

---

## 2. $O(1)$ 판별기: 2차원 누적합 (2D Prefix Sum)
이분 탐색이 던진 `Yes/No` 질문에 빠르게 대답하기 위해, 특정 구역의 합을 반복문 없이 즉시 구해내는 마법의 도구입니다.

*   **준비물:** 인덱스 에러 방지를 위해 크기를 1씩 키운 `(M+1) x (N+1)` 배열 `P`를 준비합니다.
*   **배열의 의미:** `P[r][c]`는 `(0, 0)`부터 `(r-1, c-1)`까지의 거대한 직사각형 영역의 총합입니다.
*   **점화식 (포함-배제의 원리):**
    > `P[r][c] = 현재_칸의_값 + P[r-1][c](위쪽) + P[r][c-1](왼쪽) - P[r-1][c-1](중복 대각선)`

---

## 3. 구역합 도출 (가위질 마법)
누적합 배열 `P`가 완성되면, 사막 한가운데 떠 있는 `H x W` 크기의 선인장 구역 합을 단 4개의 꼭짓점 숫자로 계산할 수 있습니다.

*   **공식:** `합 = 가장_큰_색종이 - 위쪽_자르기 - 왼쪽_자르기 + 중복_복구하기`
*   **코드:** `area_sum = P[i+H][j+W] - P[i][j+W] - P[i+H][j] + P[i][j]`
*   이 계산 결과가 `0`이라면, 해당 구역 내에는 위험 요소가 단 하나도 없다는 뜻(`Yes`)이 됩니다.

---

## 4. 실전 활용 가이드 (언제 이 무기들을 꺼내야 할까?)

### 🚨 매개변수 탐색 (Parametric Search) 발동 조건
1. **탐색 범위가 비정상적으로 클 때:** 정답의 범위가 10억, 100억 단위라서 $O(N)$으로 하나씩 확인하면 무조건 시간 초과가 날 때.
2. **"~의 최댓값/최솟값을 구하시오":** 문제에서 구하라는 것이 최적의 '값' 자체일 때.
3. **결정이 연속적일 때:** 정답을 기준으로 Yes/No의 경계가 뚜렷하게 나뉘어 스무고개가 가능할 때.
> **💡 대표 문제 유형:** 길이 자르기 (랜선 자르기, 나무 자르기), 시간/비용 최소화 (입국심사)

### 🚨 누적합 (Prefix Sum) 발동 조건
1. **구간의 합을 '여러 번' 물어볼 때:** 반복문 안에서 똑같은 구간을 계속 다시 더해야 하는 '중복 계산의 늪'에 빠졌을 때.
2. **배열의 값이 중간에 바뀌지 않을 때:** (배열의 값이 중간에 계속 업데이트된다면 세그먼트 트리 등 다른 기법이 필요합니다.)
3. **2차원 배열에서 넓은 구역을 다룰 때:** $H \times W$ 같은 거대한 2차원 구역의 정보를 단숨에 $O(1)$로 요약해야 할 때.
> **💡 대표 문제 유형:** 단순 구간 합 쿼리 처리, 연속된 부분 배열의 합 (투 포인터와 결합), 2차원 변화량 기록 (IMOS 기법 - 카카오 파괴되지 않은 건물)

## 5. 실전 템플릿 코드
```python
def solution(M, N, H, W, drops):
    # 1. 초기 상태 세팅 (비가 오지 않는 곳은 무한대로 설정)
    grid = [[int(1e9)] * N for _ in range(M)]
    for order, (x, y) in enumerate(drops, 1):
        grid[x][y] = order

    # 2. 결정 함수 (T초일 때 버틸 수 있는 자리가 있는가?)
    def check(T):
        P = [[0] * (N + 1) for _ in range(M + 1)]
        
        # 누적합 배열 완성
        for r in range(1, M + 1):
            for c in range(1, N + 1):
                is_danger = 1 if grid[r-1][c-1] <= T else 0
                P[r][c] = is_danger + P[r-1][c] + P[r][c-1] - P[r-1][c-1]
                
        # 4개 꼭짓점으로 영역 합 검사 (가위질)
        for i in range(M - H + 1):
            for j in range(N - W + 1):
                area_sum = P[i+H][j+W] - P[i][j+W] - P[i+H][j] + P[i][j]
                if area_sum == 0:
                    return [i, j] # '가장 위, 왼쪽' 명당 즉시 반환
        return None

    # 3. 매개변수 탐색 (스무고개)
    left, right = 0, len(drops)
    answer = [0, 0]
    
    while left <= right:
        mid = (left + right) // 2
        result = check(mid)
        
        if result is not None:
            answer = result
            left = mid + 1  # 더 오래 버틸 수 있는지 확인
        else:
            right = mid - 1 # 못 버티면 시간을 줄임
            
    return answer
